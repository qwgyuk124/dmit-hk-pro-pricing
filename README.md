## Pro、EB、T1 三档怎么选

看你的运营商和用途，规则不多：

**电信用户，且延迟直接影响业务** → 香港 Pro。电信回程走 CN2 GIA，晚高峰最稳，这是 DMIT 的看家产品。预算只够一台的话，Pro.TINY 是起点。

**联通、移动用户** → 香港 EB。走三网 CMI，$29.90 换 1000GB，比 Pro 便宜还多一倍流量。电信用户用 EB 也能跑，只是优化优先级不如 Pro。

**只要香港地理位置，不要大陆优化** → 香港 T1。$6.90/月 2000GB，做落地、做国际业务出口、做监控节点都合适。别指望它晚高峰给你 CN2 的体验。

**要跑流媒体、大流量转发、预算优先** → 洛杉矶 Pro 或 EB。$9.99 起步，流量配额大，10Gbps 带宽档位在香港是没有的。

**面向海外用户的站、API 节点、CDN 边缘** → T1，超量后限速不停机，不会因为跑超流量被额外计费。

## 买之前必须知道的六个限制

**只提供 Linux，没有 Windows。** 需要 Windows 环境的直接排除，不用往下看。

**强制 SSH 密钥登录，不支持 root 密码。** 首次购买后要去后台下载密钥文件，再用 SSH 客户端连接。对习惯了密码登录的人是第一个卡点，提前准备好客户端。

**IP 被墙每 15 天可免费换一次，其他情况 $5/次。** 这个政策对需要频繁更换出口的用户友好，但别把它当无限换 IP 用。

**退款：3 天内流量不超过 30GB 可全额退，30 天内按剩余价值退。** 退回账户余额免手续费，原路退回要扣支付网关手续费。买之前先用月付测一轮，比事后走退款流程省事。

**Pro 以外的产品可能切换路由。** 官方对 EB、T1 保留因网络攻击或成本原因调整线路的权利。如果高端优化线路是硬需求，直接买 Pro，别在 EB 上赌。

**硬件升级维护可能不提前邮件通知。** 有测评提到这点被用户吐槽过。跑对稳定性要求极高的业务，要留冗余。

另外，T1 系列流量超量后限速不停机，最高限速 1Gbps，不额外收费。对流量预估不准的场景，这条比"超量停机"友好得多。

## 常见问题

**香港节点延迟到底多少？**
多数测评落在 30–50ms，电信 CN2 GIA 回程下更靠近 30ms，有测评给出国内平均 39ms。部分资料写 10–50ms，那是把华南地区的最好成绩也算进去了。晚高峰会比闲时高一些。

**能解锁 Netflix 吗？**
DMIT 提供原生 IP，YouTube Premium 多数情况可以，Netflix 和 Disney+ 不保证 100%。买之前问客服当前 IP 段的解锁情况，比买完再试靠谱。

**能装 Windows 吗？**
不能，只提供 Linux 镜像。

**为什么经常显示缺货？**
有测评提到 DMIT 控制单台母机的用户数、不超售，热门套餐补货慢。看中了别拖，缺货就得等。

**香港 Pro 的 500GB 流量够用吗？**
折算下来每天约 16.7GB。普通企业站、博客、API 服务够用；做中转、大文件分发、视频流量不够，这类需求看 EB 的 1000GB 或者干脆去洛杉矶。

**客服能中文沟通吗？**
工单系统界面和文档以英文为主，工单内容可以用中文提，响应速度尚可。
